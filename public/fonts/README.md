# Fonts

このディレクトリに **2 つのフォント** を手動配置する必要があります。リポジトリには商用配布できないため含めていません。

## 必要ファイル

### 1. `PrintChar21.ttf` (英語用)

- 入手先: [Kreative Software - Apple II fonts](http://www.kreativekorp.com/software/fonts/apple2.shtml)
- ファイル名: `PrintChar21.ttf` にリネームして配置
- 用途: Apple II 風 7×8 ピクセル英語フォント
- ライセンス: 配布元で確認 (本プロジェクトは非営利)

### 2. `MisakiGothic.ttf` (日本語用)

- 入手先: [美咲フォント](https://littlelimit.net/misaki.htm) (門田暁人 氏作)
- ファイル名: `MisakiGothic.ttf` にリネームして配置
- 用途: 8×8 ピクセル日本語フォント
- ライセンス: 自由配布可 (詳細は配布元参照)

## 動作確認

両ファイルを配置した後、`pnpm dev` で開発サーバを起動し、Title 画面が以下のように表示されれば OK:

- 英語表示時: Apple II HGR 風のクラシックな書体
- 日本語表示時: PC-9801 風の 8x8 ピクセル日本語

フォントが見つからない場合、ブラウザはフォールバック monospace で描画するためレイアウトが崩れる可能性があります。

## なぜリポジトリに含めないか

両フォントとも「個人利用は自由」だが、商用または再配布の条件が個別に異なります。本プロジェクトは MIT ライセンスでオープンソース化するため、フォントは外部依存とし、各自で取得していただく方針です。
