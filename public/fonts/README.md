# Fonts

このディレクトリには **2 つのフォント** が同梱されています（ライセンス的に再配布可のため、各自ダウンロード不要）。

## 同梱フォント

### `PrintChar21.ttf` (英語用)

- **用途**: Apple II 風 7×8 ピクセル英語フォント
- **入手元**: [OnlineWebFonts.com - Print Char 21](https://www.onlinewebfonts.com/)
- **ライセンス**: CC BY 4.0
- **クレジット**: Fonts made from [Web Fonts](https://www.onlinewebfonts.com) is licensed by CC BY 4.0

### `MisakiGothic.ttf` (日本語用)

- **用途**: 8×8 ピクセル日本語フォント
- **入手元**: [美咲フォント](https://littlelimit.net/misaki.htm) (門田暁人 氏作)
- **ライセンス**: 自由配布可

## 動作確認

両ファイル配置後、`pnpm dev` で開発サーバを起動し、Title 画面が以下のように表示されれば OK:

- 英語表示時: Apple II HGR 風のクラシックな書体
- 日本語表示時: PC-9801 風の 8x8 ピクセル日本語

CC BY 4.0 ライセンスのため、本プロジェクトの表示物 (README, アプリ内クレジット等) に Print Char 21 の出典を明記する必要があります。本プロジェクトは README.md の「謝辞」セクションでクレジットを記載しています。
